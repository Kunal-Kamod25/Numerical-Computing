STUDY GUIDE: CurveFitting.hpp Analysis
==========================================

This file defines the architecture for mathematical Curve Fitting using Object-Oriented Programming (OOP) in C++.

1. INHERITANCE HIERARCHY
------------------------
Matrix (Base) -> CurveFitting (Abstract Base) -> LeastSquares (Concrete Class)

* What is inherited from Matrix?
  - Data Storage: The internal 2D array/vector that holds numbers.
  - Dimensions: Variables tracking rows and columns.
  - Basic Logic: Methods for printing data or performing basic arithmetic.

2. CLASS: CurveFitting (Abstract)
---------------------------------
This class defines the "Interface" for all curve fitting modules.

- Role: It manages the raw data points (Xi, Fi) but doesn't know the math for the fit yet.
- Key Methods:
  * setData(): Stores input vectors into the inherited Matrix storage (N rows x 2 columns).
  * pointCount(): Returns the number of data points.
  * virtual fit() = 0: A PURE VIRTUAL function. Every subclass (like LeastSquares) MUST implement its own math logic to solve for coefficients.
  * evaluate(): Blueprint for predicting Y given an X.
  * rms(): Blueprint for calculating error (Root Mean Square).

3. CLASS: LeastSquares (Concrete)
---------------------------------
This is the implementation of Linear Regression (fitting a straight line y = ax + b).

- Private Members:
  * a: Stores the calculated Slope.
  * b: Stores the calculated Intercept.

- Mathematical Logic (The fit() method):
  It solves the "Normal Equations" derived from calculus:
  1) a * sum(xi^2) + b * sum(xi) = sum(xi * fi)
  2) a * sum(xi)   + b * N       = sum(fi)

- key Methods:
  * fit(): Executes the math above to find 'a' and 'b'.
  * evaluate(): Returns (a * x + b).
  * rms(): Calculates the standard error sqrt(Sum(Residuals^2) / N).

4. WHY THIS STRUCTURE?
----------------------
- Modularity: If you want to add "PolynomialFitting" or "ExponentialFitting," you just create a new class that inherits from CurveFitting and change the fit() logic.
- Reuse: All classes share the same data handling logic from the top-level Matrix class.
- Extensibility: The evaluateRange() method in the base class works for ALL types of fits automatically.
