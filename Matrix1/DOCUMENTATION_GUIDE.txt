KEY ALGORITHMS AT A GLANCE
═════════════════════════════════════════════════════════════════════════════════

GERSHGORIN CIRCLE THEOREM:
──────────────────────────
For each row i of matrix A:
  Center_i = A[i][i]            (diagonal element)
  Radius_i = Σ |A[i][j]|        (sum of absolute values, j ≠ i)
            j≠i

Eigenvalue bounds:
  min_eigenvalue = min(Center_i - Radius_i)
  max_eigenvalue = max(Center_i + Radius_i)

Cost: O(n²) - must scan entire matrix
Result: Quick bounds (not exact eigenvalues)


LAGRANGE POLYNOMIAL INTERPOLATION:
──────────────────────────────────
For data points (x_0,y_0), ..., (x_{n-1}, y_{n-1}):

Lagrange Basis: L_i(x) = ∏ (x - x_j) / (x_i - x_j)  where j ≠ i
                         j

Polynomial:     P(x) = Σ y_i * L_i(x)
                      i

Properties:
  ✓ P(x_i) = y_i  (passes through all points)
  ✓ Degree ≤ n-1
  ✓ Unique (only one polynomial of this degree through n points)

Cost per evaluation: O(n²)
Result: Exact polynomial through all points


═════════════════════════════════════════════════════════════════════════════════
WHEN TO USE EACH ALGORITHM
═════════════════════════════════════════════════════════════════════════════════

Use Gershgorin (Eigenvalues.hpp / Gershgorin.hpp) when:
  ✓ You have a matrix A and want eigenvalue information
  ✓ You need quick bounds (not exact eigenvalues)
  ✓ You want to check if matrix is invertible (0 not in Gershgorin disk)
  ✓ You need spectral radius bounds for convergence analysis
  ✓ You want to understand matrix properties quickly
  ✓ Computational speed is critical (O(n²) vs O(n³) for exact eigenvalues)

Use Lagrange Interpolation (Interpolation.hpp / Lagrange) when:
  ✓ You have data points and want a smooth curve through them
  ✓ You need to evaluate function at new points between known points
  ✓ You need exact polynomial passing through all data points
  ✓ You have n < 10 points (avoid Runge oscillation for large n)
  ✓ You want fast polynomial evaluation (O(n²) per point)
  ✓ You need curve fitting for visualization/reporting
