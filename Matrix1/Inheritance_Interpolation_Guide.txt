============================================================
  EIGENVALUES -> INTERPOLATION -> LAGRANGE (LEARNING GUIDE)
============================================================

New class structure:

1) Matrix -> Eigenvalues
   - File: Include/Interpolation.hpp, Src/Interpolation.cpp
   - Purpose:
     Reuses Matrix and Gershgorin methods through a dedicated class name.
   - Key methods:
     - getDisks()
     - getRealBounds()

2) Interpolation (separate from Matrix)
   - File: Include/Interpolation.hpp, Src/Interpolation.cpp
   - Purpose:
     Stores interpolation points xData/yData and validates data.
   - Key methods:
     - setData(x, y)
     - pointCount()
     - getX(), getY()

3) Interpolation -> Lagrange
   - File: Include/Interpolation.hpp, Src/Interpolation.cpp
   - Purpose:
     Implements Lagrange polynomial interpolation.
   - Key methods:
     - evaluate(x)
     - evaluateRange(xMin, xMax, samples)

------------------------------------------------------------
HOW THE FLOW WORKS

A) Eigenvalues stage (Matrix branch)
   - Read matrix A
   - Compute Gershgorin disks and real bounds

B) Interpolation stage (independent branch)
   - Build (x, y) points from matrix-derived data
     Example in this code: x = index, y = disk radius

C) Lagrange stage
   - Build polynomial from points
   - Evaluate at target x or on a full range

------------------------------------------------------------
CHECK DATA FOR 49 CASE

- File: Large_Matrix/interpolation_check_data.txt
- Why:
  49-size inputs can be noisy/unstable for interpolation demos.
  So we include known stable points for correctness checking.

- If check file is not available, code falls back to built-in data:
  x = -3..3
  y = x^2 + 2x + 1 pattern-like smooth dataset
