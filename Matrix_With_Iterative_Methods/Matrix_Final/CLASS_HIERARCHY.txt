===============================================
  JACOBI vs GAUSS-SEIDEL COMPARISON
===============================================

JACOBI METHOD:
--------------
For each component i:
    sum = 0
    for j = 0 to n-1:
        if j ≠ i:
            sum += A[i][j] * x_previous[j]  ← Uses OLD values
    
    x_current[i] = (b[i] - sum) / A[i][i]

Update ALL components, THEN copy to previous

Characteristics:
  ✓ Can parallelize (all updates independent)
  ✓ Simple to implement
  ✗ Slower convergence
  ✗ More iterations needed


GAUSS-SEIDEL METHOD:
--------------------
For each component i:
    sum = 0
    
    for j = 0 to i-1:
        sum += A[i][j] * x_current[j]  ← Uses NEW values (j < i)
    
    for j = i+1 to n-1:
        sum += A[i][j] * x_current[j]  ← Uses OLD values (j > i)
    
    x_current[i] = (b[i] - sum) / A[i][i]

Update component i IMMEDIATELY before moving to i+1

Characteristics:
  ✓ Faster convergence
  ✓ Fewer iterations needed
  ✗ Sequential (hard to parallelize)
  ✗ More complex data dependencies


===============================================
  MEMORY LAYOUT
===============================================

BaseMatrix:
┌─────────────────────────────────────┐
│ rows: int                           │
│ cols: int                           │
│ mat: vector<vector<long double>>   │
│ solution_vec: vector<long double>  │
└─────────────────────────────────────┘

Matrix (inherits BaseMatrix + adds):
┌─────────────────────────────────────┐
│ ... inherited fields ...            │
│ + operator overloads                │
│ + utility methods                   │
└─────────────────────────────────────┘

IterativeSolver (inherits LinearSystem + adds):
┌─────────────────────────────────────┐
│ ... inherited fields ...            │
│ b_vec: vector<long double>          │
│ max_iterations: int                 │
│ tolerance: long double              │
│ x_current: vector<long double>      │
│ x_previous: vector<long double>     │
│ iteration_count: int                │
└─────────────────────────────────────┘

Space Complexity for n×n system:
  - Matrix A: O(n²) = n×n long doubles
  - Iterative solver: O(n) = 3 vectors of size n
  - Total: O(n²) + O(n) ≈ O(n²)

For large n, iterative methods are MUCH more memory efficient
than storing L and U matrices in LU decomposition (2×n² extra)!
