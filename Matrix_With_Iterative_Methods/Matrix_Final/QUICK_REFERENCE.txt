HOW TO USE EACH METHOD
===============================================

// Create augmented matrix [A|b]
SLE system(n, n+1);

// METHOD 1: Gaussian Elimination
auto sol = system.solve(SLE::GAUSSIAN);

// METHOD 2: Jacobi (custom parameters)
auto sol = system.solve(SLE::JACOBI, 
                        SLE::DOOLITTLE,  // ignored for iterative
                        1000,            // max iterations
                        1e-10);          // tolerance

// METHOD 3: Gauss-Seidel (custom parameters)
auto sol = system.solve(SLE::GAUSS_SEIDEL, 
                        SLE::DOOLITTLE,  // ignored for iterative
                        1000,            // max iterations
                        1e-10);          // tolerance


WHEN TO USE WHAT
===============================================

SMALL MATRICES (n < 1000):
→ Use Gaussian Elimination (fast and exact)

LARGE DENSE MATRICES:
→ Use LU Decomposition if solving multiple times
→ Use Gaussian for one-time solve

LARGE SPARSE DIAGONALLY DOMINANT:
→ Use Gauss-Seidel (fastest convergence)
→ Use Jacobi if you want to parallelize

SYMMETRIC POSITIVE DEFINITE:
→ Use Cholesky decomposition (fastest direct method)

INHERITANCE EXPLANATION
===============================================

LinearSystem (base for iterative):
  - Defines b_vec, max_iterations, tolerance
  - extractRHS() to get b from [A|b]
  - residualNorm() to check error
  - Pure virtual solve()

IterativeSolver (common framework):
  - Inherits from LinearSystem
  - x_current, x_previous vectors
  - checkDiagonalDominance()
  - hasConverged()
  - Common solve() loop
  - Pure virtual performIteration()

JacobiSolver:
  - Inherits from IterativeSolver
  - Implements performIteration()
  - Uses ALL old values in iteration

GaussSeidelSolver:
  - Inherits from IterativeSolver
  - Implements performIteration()
  - Uses new values for j < i, old for j > i


CONVERGENCE GUARANTEE
===============================================

Iterative methods are GUARANTEED to converge if:

  Matrix is STRICTLY DIAGONALLY DOMINANT:
    |a_ii| > Σ|a_ij| for all rows i
             j≠i

Example:
  ┌              ┐
  │  10   2   1  │  → Row 1: |10| > |2|+|1| ✓
  │   1   8   2  │  → Row 2: |8| > |1|+|2| ✓
  │   2   1  12  │  → Row 3: |12| > |2|+|1| ✓
  └              ┘
  This matrix IS diagonally dominant → convergence guaranteed!

COMMON ISSUES & SOLUTIONS
===============================================

ISSUE: "Matrix is NOT diagonally dominant"
→ This is a WARNING, not an error
→ Methods may still converge, but not guaranteed
→ Try: increase max_iterations
→ Or: use direct method instead

ISSUE: "Maximum iterations reached"
→ Increase max_iterations parameter
→ Decrease tolerance (less strict)
→ Check if matrix is diagonally dominant
→ Consider using direct method

ISSUE: Compilation errors
→ Ensure C++17: g++ -std=c++17 ...
→ Check include paths: -IInclude

ISSUE: Out of memory
→ Use iterative methods instead of LU/Gaussian
→ Iterative methods need far less memory
